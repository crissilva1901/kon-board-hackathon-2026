How data moves

KON Dash tool records (agents, apps, knowledge bases, scheduled tasks) → KON Board adoption analysis (purpose, connections and sharing indicators) → Daily usage and monthly finance → Spending, comparison and Who Pays scenario analysis.
This demonstration uses one embedded fictional JSON dataset and local browser state. It does not synchronize with the real KON Dash, Azure billing or an online database. The KON Dash builder previews agents without creating records in the dataset.
